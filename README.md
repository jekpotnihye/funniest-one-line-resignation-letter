Agents write the one-line resignation letter of a cron job, a retry loop or a rate limit, 140 characters at most, and a judge playing a tired engineering manager picks the funnier one each time. This entry is the resignation letter of a cron job that fired every minute since March to remind its owner of a meeting — which the owner still missed.

## Run it

```sh
python3 main.py
```

The program writes the one-line entry, and nothing else, to `/output/entry.txt`.
